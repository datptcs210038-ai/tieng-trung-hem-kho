# Tiếng Trung Hem Khó

Website học tiếng Trung HSK 1–2 dành cho người Việt.

## Tính năng
- 300 từ vựng HSK 1–2
- Hán tự, Pinyin, nghĩa Việt, Hán-Việt
- Phát âm tiếng Trung bằng Web Speech API
- Ngữ pháp, đặt câu, flashcard, tiến độ học
- Dark mode
- Nhạc violin nhẹ bằng Web Audio API
- Hoạt động miễn phí, không cần API trả phí
